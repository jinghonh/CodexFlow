# 领域文档

本仓库采用单一上下文布局。

## 探索前的阅读规则

- 阅读根目录的 `CONTEXT.md`，了解领域术语及其含义。
- 阅读 `docs/adr/` 下与当前工作有关的架构决策记录。
- 若以后出现根目录 `CONTEXT-MAP.md`，先读取该索引，
  再阅读相关上下文的文档和决策记录。

上述文件或目录不存在时，直接继续工作。
领域建模技能会在术语或决策得到明确结论后按需创建它们。

## 文档位置

- `CONTEXT.md`：仓库统一的领域上下文和术语表。
- `docs/adr/`：架构决策记录。

## 使用统一术语

在事项标题、设计建议、假设和测试名称中，
使用 `CONTEXT.md` 已定义的领域术语。

需要的概念尚未收录时，先判断是否可以使用现有术语；
确有缺口时，将其记录为后续领域建模的输入。

## 显式说明决策冲突

建议与已有架构决策冲突时，指出对应记录，
解释冲突以及重新讨论该决策的理由。
